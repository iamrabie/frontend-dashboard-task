Project Overview

This project is a React-based analytics dashboard that visualizes system metrics using charts and statistic cards. It fetches data from fake APIs and supports dynamic data refresh.

Tech Stack

React.js

Recharts

Tailwind CSS

JavaScript (ES6+)

DummyJSON API

Setup Instructions

Clone the repository

Run npm install

Run npm run dev

Open http://localhost:5173 in browser

Key Decisions and Trade-offs

Used Recharts for simple and fast chart integration

Used DummyJSON for mock backend data

Used random data generation to simulate refresh behavior

Used Tailwind CSS for faster UI development
